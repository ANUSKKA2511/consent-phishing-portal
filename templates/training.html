You just submitted credentials to a fake login page. Nothing was stored — but in a real attack, those details would now belong to an attacker.

🚩 Red flags you could have spotted

1. The URL was fake. it-portal.company-secure-login.com is not your company domain — the real domain is at the end before the first slash.
2. "Session expired" pressure. Attackers use urgency so you don't stop to check.
3. Credential re-entry. Legitimate portals almost never ask you to re-type your password from an email link.
4. No padlock / no MFA prompt. Real corporate logins usually ask for an authenticator code.

✅ What to do next time

  • Hover over links and read the URL before clicking.
  • Type the known URL directly instead of following email links.
  • Report suspicious messages to IT immediately.
